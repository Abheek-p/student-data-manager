# My Python Mini Projects: Student Results + Contact Book

Hey! This repo has the two Python projects I built while learning the basics. I wanted to make something that actually works and feels useful instead of just doing random practice problems, so here we are.

1. **Student Result Management System**: you add students and their marks, and it figures out the total, percentage and grade for you. I liked this one because it felt like a real school tool.
2. **Contact Book**: a CRUD app that saves contacts in a JSON file and lets you export them to CSV. Basically my own tiny version of the contacts app on your phone.

Both run in the terminal with a simple menu, and I stuck to Python's standard library, so there's nothing to install. Just run it and go.

## Which one should you look at?
Each folder is its own project, so pick whichever fits your assignment. If you want to reuse one, you can copy the folder into its own GitHub repo.

## What I learned (and got stuck on a few times)
- Variables and data types

- Loops and if/else statements
- Input validation (my program crashed a lot before I added this)
- File handling

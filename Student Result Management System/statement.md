# Project Statement — Student Result Management System

## Problem Statement
Managing student marks manually can make searching, updating and calculating results inconvenient. This project provides a simple command-line system that stores student information and marks in a JSON file.

## Objectives
- Store student records permanently.
- Calculate totals, percentages and grades.
- Provide CRUD-style record management.
- Demonstrate dictionaries, lists, functions, loops, conditions and file handling.
- Provide basic result statistics.

## Core Data
Each student record contains roll number, name, course/class, subject marks, total, percentage and grade.

## Storage
JSON is used for persistent local storage. No external database is required.

# Project Statement — Contact Book

## Problem Statement
A contact list becomes difficult to maintain when records are stored only on paper or as unstructured text. This project provides a simple command-line Contact Book that supports CRUD operations and persistent file storage.

## Objectives
- Create new contacts.
- View and search contacts.
- Update existing contacts.
- Delete contacts.
- Store contacts in JSON.
- Export contacts to CSV.
- Demonstrate Python file handling and structured data.

## Core Data
Each contact contains an ID, name, phone number, email and address.
